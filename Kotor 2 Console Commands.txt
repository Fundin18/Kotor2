====================================================================
CONSOLE COMMANDS & ATTRIBUTES
====================================================================

[CORE ENGINE & UTILITY COMMANDS]
heal                     - Maxes out health and force points for active party
invulnerability          - Toggle god mode (main character takes zero damage)
infiniteuses             - Item/shield/tool quantities never deplete
turbo                    - Speeds up general game pace and movement speed
revealmap                - Uncovers the entire map overlay for your zone
bright                   - Disables dark shadows and fog of war lighting
whereami                 - Prints active X, Y, Z coordinate values to logs
restartminigame          - Restarts a stuck or failing turret/swoop minigame
dance_dance_revan        - Easter Egg: Turn final area characters into Twi'leks

[CHARACTER PROGRESSION & ALIGNMENT]
addexp [number]          - Adds specified amount of experience points
addlevel [number]        - Instantly increases level by specified number
addlightside [number]    - Shifts alignment toward Light Side by amount
adddarkside [number]     - Shifts alignment toward Dark Side by amount
givecredits [number]     - Spawns the specified amount of credits

[STAT ATTRIBUTE SETTERS (Usage: setattribute [0-5] [3-99])]
setattribute 0 [3-99]    - Set raw Strength attribute score
setattribute 1 [3-99]    - Set raw Dexterity attribute score
setattribute 2 [3-99]    - Set raw Constitution attribute score
setattribute 3 [3-99]    - Set raw Intelligence attribute score
setattribute 4 [3-99]    - Set raw Wisdom attribute score
setattribute 5 [3-99]    - Set raw Charisma attribute score

[SKILL SETTERS (Usage: setskill [0-7] [3-99])]
setskill 0 [3-99]        - Set Computer Use skill level
setskill 1 [3-99]        - Set Demolitions skill level
setskill 2 [3-99]        - Set Stealth skill level
setskill 3 [3-99]        - Set Awareness skill level
setskill 4 [3-99]        - Set Persuade skill level
setskill 5 [3-99]        - Set Repair skill level
setskill 6 [3-99]        - Set Security skill level
setskill 7 [3-99]        - Set Treat Injury skill level

[STANDALONE MACROS (Do NOT use 'giveitem' prefix)]
givemed                  - Spawns a bundle of standard Medical Packs
giverepair               - Spawns a bundle of Droid Repair Kits
givecomspikes            - Spawns a bundle of Computer Spikes
givesitharmor            - Spawns quest-specific Sith Armor (Taris style)
